## Visual rules

Always preserve:
- existing visual language
- hierarchy
- typography rhythm
- readable contrast
- warm cream/green/coffee/gold palette
- calm premium spacing

Avoid:
- washed-out text
- plain white card overload
- headings competing with hero h1
- accidental redesigns
- new CTAs that V1 did not have unless requested
- making sections look too similar to existing components

## Public-only nav rule
